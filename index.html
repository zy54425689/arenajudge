A prize in escrow, and a referee that reads both sides instead of trusting the host.

A tournament host escrows the prize and writes the rules. The two players each submit the artifact that proves their side — match log, replay, screenshot set. An on-chain jury fetches both artifacts and names the winner under the stated rules; the winner claims the prize. If an artifact cannot be retrieved, nobody wins and nobody forfeits: the match simply goes inconclusive and the host gets the prize back.

How it works

  1. create_match (payable) — the host escrows the prize, names the two players and writes the rules.
  2. submit_evidence — each named player submits one artifact URL. The host cannot play.
  3. judge_match — the jury fetches both artifacts on-chain and names A, B or a draw under the stated rules. If an artifact cannot be retrieved the match becomes INCONCLUSIVE: nobody wins, nobody forfeits. Judging is bounded to 3 rounds.
  4. claim_prize — credits the winner (a draw splits the prize). withdraw_credit then moves it out — the credit is zeroed first, so a duplicate payout is impossible.
  5. refund — the host reclaims the prize if the match never reached a verdict.
